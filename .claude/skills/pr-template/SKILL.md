name: pr-template
description: Defines the expected template of any pull requests submitted for this repo. Follow it exactly when filling out a pull request body. Keep it in laymans terms, keep verbosity down. No robospeak. Use a sonnet sub agent to write the PR contents. 
---

### Related Issues

Link any related issues.

### Problem

What are we solving. What is the benefit of what we are solving.
2-3 plain english sentences.

### Solution

How we solved it.
2-3 plain english sentences on how the problem was solved. Such as "We removed x,y,z from files a,b,c"

### Files Touched

List of files touches in this PR and why they were. Justify why they were important.

### Tests

List of tests included in the PR and what they acocmplish
